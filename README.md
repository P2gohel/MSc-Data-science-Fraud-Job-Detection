# Detecting Fraudulent Job Postings: A Comparative Machine Learning Approach

---

## Project Overview

This project develops an automated machine learning system for detecting fraudulent job postings.
Two classifiers — Logistic Regression and Support Vector Machine (SVM) — are compared using
TF-IDF text features. The output is an interpretable fraud-likelihood score (probability),
not a binary label, so end users can make informed decisions.

## Dataset

[Real or Fake: Fake Job Posting Prediction (Kaggle, 2020)](https://www.kaggle.com/datasets/shivamb/real-or-fake-fake-jobposting-prediction)

- 17,880 job postings
- 866 fraudulent (4.84%) — heavy class imbalance
- 18 columns: text fields (title, description, requirements, benefits)
  and structured fields (has_company_logo, telecommuting, employment_type)

## Methodology

1. **EDA** — explore class balance, feature distributions and text patterns
2. **Preprocessing** — text cleaning, lemmatisation, missingness flags as features
3. **Feature Engineering** — TF-IDF on combined text fields + 6 binary metadata features
4. **Modelling** — Logistic Regression vs SVM with stratified 80/20 train/test split
5. **Imbalance Handling** — compare `class_weight='balanced'` and SMOTE
6. **Evaluation** — accuracy, precision, recall, F1, AUC-ROC, confusion matrices, 5-fold cross validation
7. **Explainability** — SHAP word-level explanations on the chosen model
8. **Prototype** — interactive interface showing fraud probability and key influencing words


## Results

| Model | Accuracy % | Fraud Precision % | Fraud Recall % | Fraud F1 % | AUC-ROC |
|---|---|---|---|---|---|
| LR — Baseline | 97.26 | 98.70 | 43.93 | 60.80 | 0.9814 |
| LR — Class Weighting | 95.72 | 53.40 | 90.75 | 67.24 | 0.9887 |
| LR — SMOTE | 97.18 | 65.13 | 89.60 | 75.43 | 0.9899 |
| SVM — Baseline | 98.85 | 97.14 | 78.61 | **86.90** | 0.9895 |
| SVM — Class Weighting | 98.74 | 95.07 | 78.03 | 85.71 | 0.9900 |
| SVM — SMOTE | 98.69 | 96.32 | 75.72 | 84.79 | 0.9876 |

5-fold cross validation: LR class weighted 0.667 (± 0.016), SVM baseline 0.829 (± 0.024)

### Key Findings

- **Accuracy is misleading with imbalanced data** — baseline LR scored 97% accuracy but caught only 44% of fraud
- **Imbalance handling is model-dependent** — transformed LR (recall 44% → 91%) but had no effect on SVM
- **SVM baseline is the best overall performer** (F1 86.90) with only 4 false alarms
- **LR with class weighting catches the most fraud** (misses only 16 of 173) — chosen for the prototype for its recall and exact SHAP interpretability, with SVM reported as the performance ceiling

## Key EDA Findings

- Severe class imbalance (4.84% fraud) — accuracy is not a reliable metric
- `has_company_logo` is the strongest single signal of legitimacy
- Part-time and "Other" employment types have higher fraud rates than full-time
- Fake postings use distinctive vocabulary (*work from home*, *earn*, *data entry*)


- **Model complexity did not improve detection** — the ANN (F1 84.15) did not outperform the simpler SVM, despite substantially greater complexity
